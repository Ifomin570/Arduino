## 2. Что такое Arduino простыми словами

[What is Arduino?](https://images.openai.com/static-rsc-4/vky5nJkSM18oaMFEk62Y-umX1kbjcAFbsmEQlamZFsQtCzbhFBgFq4VrcwS_TcKpmVeY0iW4rmvJbzzWkFHeBBQV-Z-WAcM7I17g-Jdbqtuubb8mC9tBw-9BHJUAYK8Tb8IkWQciFcKSPar7ZRMf1DRjXdUGZdpkexUma8mhwRk?purpose=inline)

Arduino — это плата, которая выполняет нашу программу и управляет подключёнными устройствами.

Например:

- светодиодом — управляет светом;
- кнопкой — получает сигнал о нажатии;
- датчиком температуры — получает данные об окружающей среде;
- зуммером — управляет звуком.

На нашей плате есть небольшой компьютер — микроконтроллер. В этом уроке мы работаем с классическими Arduino Uno R3 и Nano на микроконтроллере ATmega328P.

### Как работает устройство

1\. Программа

Мы пишем команды на компьютере.

2\. Arduino

Микроконтроллер выполняет команды.

3\. Светодиод

Получает управляющий сигнал и загорается.

Главная идея: мы пишем код, а Arduino выполняет его и управляет реальными компонентами.

## 4. Как электричество проходит по цепи

Для начала запомним три обозначения.

- D4 — цифровой контакт Arduino, которым мы будем управлять.
- GND — общий провод, условно называемый «землёй».
- HIGH / LOW — два состояния цифрового выхода: высокий и низкий уровень.

Светодиод имеет два вывода:

- A (анод) — положительный вывод;
- C (катод) — отрицательный вывод.

В нашем учебном проекте соединения будут такими:

## Схема подключения

Arduino — контакт D4

Анод A светодиода

Катод C → резистор 220 Ом

Arduino — контакт GND

Схема показывает порядок соединений. В Wokwi провода нужно соединить с соответствующими контактами компонентов.

Почему всё устроено именно так?

1. Arduino подаёт управляющий сигнал на D4.
2. Ток проходит через светодиод.
3. Резистор ограничивает ток.
4. Цепь возвращается к GND.

Если светодиод подключить наоборот, он может не загореться. Если забыть резистор при реальной сборке, можно повредить компоненты.

Важно: перед подключением проводов к настоящей плате отключай питание. Не соединяй D4 напрямую с 5V или GND. Для первого опыта безопаснее начать с симулятора.

## 6. Шаг второй. Пишем программу

Сначала посмотрим на весь код, а затем разберём его небольшими частями.

```

const int externalLedPin = 4;

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
  pinMode(externalLedPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  digitalWrite(externalLedPin, HIGH);
  Serial.println("External LED: ON");
  delay(500);

  digitalWrite(LED_BUILTIN, LOW);
  digitalWrite(externalLedPin, LOW);
  Serial.println("External LED: OFF");
  delay(500);
}

```

Не пугайся количества команд. Программа состоит всего из двух основных частей: подготовка и повторяющиеся действия.

### Часть 1. Запоминаем номер контакта

```
const int externalLedPin = 4;
```

Разберём строку слева направо.

| Часть            | Что означает                            |
| ---------------- | --------------------------------------- |
| `const`          | Значение нельзя изменить после создания |
| `int`            | Целое число                             |
| `externalLedPin` | Имя, которое мы дали контакту           |
| `= 4`            | Запоминаем номер контакта D4            |
| `;`              | Завершаем инструкцию                    |

Зачем нужно имя `externalLedPin`?

Вместо того чтобы постоянно писать число `4`, мы используем понятное название. По нему сразу видно, что контакт управляет внешним светодиодом.

### Часть 2. Подготавливаем Arduino

```
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
  pinMode(externalLedPin, OUTPUT);
  Serial.begin(9600);
}
```

`setup()` выполняется один раз после запуска или сброса платы.

Представь, что перед работой ты готовишь рабочее место: подключаешь оборудование и проверяешь инструменты. Функция `setup()` делает примерно то же самое для нашей программы.

Разберём команды:

Команда 1

```
pinMode(LED_BUILTIN, OUTPUT);
```

Она сообщает Arduino: «Будем управлять встроенным светодиодом как выходом».

- `pinMode` — настройка режима контакта.
- `LED_BUILTIN` — обозначение контакта встроенного светодиода.
- `OUTPUT` — режим выхода, то есть Arduino будет задавать сигнал.

Команда 2

```
pinMode(externalLedPin, OUTPUT);
```

Делаем то же самое для внешнего светодиода на D4.

Команда 3

```
Serial.begin(9600);
```

Включаем последовательную связь с компьютером, чтобы Arduino могла отправлять сообщения в Serial Monitor.

Число `9600` — настройка скорости передачи данных. В мониторе порта нужно выбрать такое же значение.

После выполнения трёх команд подготовка закончена.

### Часть 3. Заставляем светодиоды включаться

```
void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  digitalWrite(externalLedPin, HIGH);
  Serial.println("External LED: ON");
  delay(500);
```

`loop()` — это часть программы, которая постоянно повторяется, пока плата работает.

Первая команда:

```
digitalWrite(LED_BUILTIN, HIGH);
```

Устанавливает высокий логический уровень на контакте встроенного светодиода. На наших платах он включается.

Вторая команда:

```
digitalWrite(externalLedPin, HIGH);
```

Включает внешний светодиод, подключённый к D4.

Третья команда:

```
Serial.println("External LED: ON");
```

Выводит в монитор сообщение:

`External LED: ON`

`println` означает, что после текста курсор переходит на следующую строку.

Четвёртая команда:

```
delay(500);
```

Останавливает выполнение следующих команд на 500 миллисекунд, то есть на половину секунды. Пока программа ждёт, светодиоды остаются включёнными.

### Часть 4. Выключаем светодиоды

```
digitalWrite(LED_BUILTIN, LOW);
digitalWrite(externalLedPin, LOW);
Serial.println("External LED: OFF");
delay(500);
```

Теперь действия выполняются в обратном порядке:

1. `LOW` — выключаем встроенный светодиод.
2. `LOW` — выключаем внешний светодиод.
3. Отправляем сообщение `External LED: OFF`.
4. Ждём ещё 500 миллисекунд.

Затем функция `loop()` заканчивается, и Arduino сразу начинает её снова.

Обрати внимание на закрывающую фигурную скобку `}` в конце каждой функции. Она показывает, где заканчивается соответствующий блок команд.

## 9. Если что-то не работает: ищем причину

Не нужно сразу переписывать всю программу. Сначала посмотри, что именно происходит.

## Выбери симптом

Встроенный мигает, внешний — нет

Оба светодиода не мигают

Светодиоды мигают, но сообщений нет

Программа не запускается из-за ошибки

Что проверить:

1. В коде указано `externalLedPin = 4`.
2. Контакт D4 действительно соединён со светодиодом.
3. Анод A подключён к D4, а катод C — через резистор к GND.
4. Резистор установлен последовательно.

При работе с настоящей платой дополнительно отключи питание и проверь соединения. Успешная симуляция не гарантирует безопасность физической схемы.

## 10. Небольшой эксперимент: меняем скорость мигания

Теперь, когда программа работает, попробуем изменить её поведение.

Найди две строки:

```
delay(500);
```

В первой версии каждая пауза длится 500 мс. Измени оба значения на `1000`:

```
delay(1000);
```

Что произойдёт?

- Светодиоды будут включены примерно одну секунду.
- Затем они будут выключены примерно одну секунду.
- Полный цикл будет занимать около двух секунд.

Попробуй также значение `200`. Светодиоды будут переключаться быстрее.

Главное правило эксперимента: меняй только одну характеристику за раз и наблюдай за результатом.
